# 例题教参说明归位规则

`scripts/example_guidance.py` 提供保守的 `prepare_example_guidance(blocks)` 预处理函数，返回新 blocks 与审计报告，不改输入 blocks 或 `batch/sections/` 原始底稿。调用方应在章节图片映射完成后、页面渲染之前调用；把返回的 blocks 传给现有页面渲染器即可。教参原文作为“教参原文提示”附在对应例题的 `teacher_analysis` 中，由现有答案/解析区渲染。

当前规则仅处理“正式教参”中标题含“分析”的块；必须同时满足：

1. 段落以明确的例题编号开头，或以“本例 / 该例”等指代紧接的例题；
2. 该段落所属的教参小节标题编号与当前题目 ID 所属节一致；
3. 被引用的全部编号在当前章节都恰有一个对应的 `category: 例题` 题块。任一编号缺失或有歧义时，整段保留原位。

多例并列、明确范围可映射到各对应题块；“例 1 是上一节例 2 的延续”一类正文里较后的交叉引用不会因此把本段误贴给例 2。以冒号结束的例题说明只会继续收录有明确编号、步骤、公式、图注等标志的紧邻段落；其他说明留在教参原位置。数学公式块作为整体保留；紧接例题说明的图像/图注与明确的“本例”“该方法”等续写一起归位，不把随后的全节一般说明整体吸收。

来源块仍留在返回值中，其未移动原文不变；`teacher_analysis` 同步带有原教参来源位置 `analysis_provenance`，另有 `teacher_guidance_sources` 记录来源块 ID、来源块行号范围和例题映射。这里的行号是原教参块的范围，不是自动推断的印刷页码，也不冒充精确逐段定位。已有解析含有相同段落时不重复追加，但仍补齐映射和来源记录；再次运行保持幂等。未能确认小节、无对应题块或引用编号不在本节的内容，都留在教参块中，并写入 `report.unmatched`，不猜测，不跨节补贴。

## 校验

```sh
PYTHONPATH=scripts python3 -m unittest scripts/test_example_guidance.py -v
```

这是规则性自动归位，不代表逐条人工核对题目与教参的语义。每次批量接入后应保存 `report`，抽查跨例题组、跨节参照、续写公式及所有 `unmatched` 项；用户查看网页时可以通过题目解析下的来源链接回查教参原文。

## 审计字段

- `source_groups` / `matched_source_groups`：起始例题说明及明确续写组成的来源组数 / 完成归位组数。
- `source_paragraphs` / `moved_source_paragraphs`：来源组包含的实际 Markdown 段落数 / 从教师总说明区归位的实际段落数。
- `attachment_count`：来源组与目标题块的对应关系数；多例共有说明会产生多个关联。
- `attached_paragraphs`：真正新增到目标解析的段落出现次数（多例复制分别计数）；`reused_existing_paragraphs` 是已在现有解析中出现而未重复追加的次数。
- `matched_examples`：发生来源关联的唯一例题题块数。
- `unmatched_groups` / `unmatched_paragraphs`：保留原处的未确认组数 / 段落数。

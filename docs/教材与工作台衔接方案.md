## 推荐目标

教材连续阅读与工作台选题编排共用结构化题目源和身份，不维护两份互不关联的可编辑正文。教材负责阅读语境，工作台负责组题、排序、保存和双版导出。

第一阶段只接题目：在受信任的工作台教材视图中，为例题/练习/习题提供“加入当前讲义”操作，复用现有题篮序列、去重与重复实例规则。独立离线教材保持可读，不显示无法执行的假按钮。

## 数据和版本规则

1. 保留样章现有题号，额外绑定不可变的书籍来源身份/修订；版本未核定时使用明确的内部语料版本，不把目录名2026当出版版次。ID不能仅靠题目文本计算，也不靠页内顺序重生成。
2. 题干、题图、答案/解答、教参分析、教师笔记独立映射到平台认可的字段；来源保留册/章/节/原题号/行号/文件哈希。图片通过资产白名单处理，不直接给浏览器任意读取本机路径的权限。
3. 首次导入预览37题和资源清单，经确认后落盘；同身份同版本不同内容拒绝。同题再次加入默认定位已有实例，“另加一份”需明确操作。
4. 讲义锁定加入时的题目版本。教材后续修订不静默替换旧讲义，更新需预览差异并确认。讲义副本的编辑不回写原教材。
5. 学生导出沿用字段排除，并检查题干/题图本身是否藏有解题痕迹；本网页的一键隐藏答案不能代替学生导出的物理隔离。

## 两条接入路线

- 首选：将本结构化底稿通过适配器导入平台认可的题包/实体模型，由受信任的教材阅读组件复用选题命令。现有离线网页仍作为阅读产物保留。
- 兼容旧网页：如确需保留隔离 iframe 中的操作，另设计受限消息桥，仅传白名单的动作、题目ID和修订；宿主校验 iframe 实例/受控资源身份后执行。不能移除 sandbox、给页面直接写工作区的能力，也不能只依赖消息中自报的来源。该桥目前未实现。

## 重要内容的展示规则

本轮已在8.1样章实现8处语义标注，底稿以 `emphases` 保存类型、稳定锚点和原文切片范围；标题注明“编辑标注”，不假称原教材版式。仅包裹既有正文，不改数学表述、不复制一份公式。

| 类型 | 作用 | 本样章实例 |
|---|---|---|
| 关键概念 | 明确对象与判别 | 相等向量比较模与方向 |
| 重要公式 | 方便定位和回看 | 向量加法运算律、数乘与数乘运算律 |
| 思想方法 | 提醒可复用的操作 | 首尾相接、减法转化为加法 |
| 条件提醒 | 避免公式脱离前提 | 平行表示的非零基准向量、单位化的非零条件 |

配色、边框和文字标签同时区分类型，不仅靠颜色。通用知识标注可以进入学生版；题后解题提示和教师批注仍不进入学生版。标注不等于数学裁定，新增内容仍需复核。暂不把公式和方法自动算作题目加入试题篮；后续可将经审核的部分适配为独立知识模块，并与题目数量分开统计。

## 首个接通样本的验收建议

先以一个例题和一道习题跑通：教材定位 → 加入题篮 → 重复定位 → 顺序调整 → 保存/刷新 → 学生/教师导出 → 来源回跳；核对题图、公式、版本锁定及学生答案隔离。通过后再扩展37题，而非先批量写入再补协议。

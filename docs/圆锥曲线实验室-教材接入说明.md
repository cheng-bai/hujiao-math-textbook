# 圆锥曲线实验室接入记录

## 本次使用的既有资产

- 原文件：`sources/visuals/圆锥曲线实验室.html`，只读保留。
- 从原文件内的 `PAGES` 提取 ellipse、hyperbola、parabola 三个独立实验室，不使用秋考题解或抛物线定点题解资产。
- 用户提供的 `http://127.0.0.1:53015/ellipse-definitions.html` 检查时未启动；已在 `sources/visuals/ellipse-definitions.html` 找到与原文件内椭圆页 SHA-256 相同的文件。运行教材不依赖这个端口，也没有启动或修改另一个项目。
- 来源、源页面及派生文件哈希见 `conic-labs-integration.json`。

## 教材位置与呈现

| 章节 | 默认入口 | 实际插入点 |
| --- | --- | --- |
| 选修一 2.2 椭圆 | 双焦点距离和 | `x1-2-2-b3` 之后、例1之前 |
| 选修一 2.3 双曲线 | 双焦点距离差的绝对值 | `x1-2-3-b3` 之后、例1之前 |
| 选修一 2.4 抛物线 | 焦点与准线等距 | `x1-2-4-b3` 之后、例1之前 |

这里的 b3 是完整“定义与标准方程推导”正文块，因此不是紧接定义句、也没有拆开原正文。

- 直接在正文默认显示；另外七个入口通过“展开7项拓展”访问，不当作并列必学定义。
- 原数学模型不改；保留条件、实时读数、边界说明与有限取样提示。
- 沿用教师页右侧资源栏、预览、插入、移除、重置、撤销、配置导入导出和学生页显隐控制。
- 初次兼容旧配置时追加三个默认模块，不丢原有椭圆拉绳或线面垂直编排。用户移除后不自动补回；显式导入布局以导入结果为准。
- 每节仅加载对应实验室，而非加载整个三曲线合集；移除椭圆页重复内嵌的拉绳实验，原拉绳模块仍可单独使用。
- 教师推导按原逻辑保留。学生资源单独生成，清除各场景 proof 数据和教师提问内容，移除教师推导 DOM 及打印时强开推导监听；学生 ZIP 不打包教师实验室 JS。
- 沿用原打印策略：完整内容使用小型静态代表图，不打印 iframe 控件；仅试题和正文模式不夹带交互模块。代表图不是当前拖动状态截图。
- 修复离屏 iframe 在桌面切手机后高度未更新的问题：宿主页补测宽度、可见性与窗口变化，子页补测正文和字体；避免手机内容被旧高度截断。

## 实际验证

最终定向验收：`outputs/五册教材教参整合/x1/conic-verification/20261019-234858/results.json`。

- 152 项检查通过，浏览器 JavaScript 错误为 0。
- 三种曲线、教师/学生两版、每版八场景切换与公式渲染。
- 桌面与 390px 手机宽度、 iframe 全内容高度及参数重载恢复。
- 教师推导展开、学生推导隔离、旧配置保留、移除后不回填、显式空布局导入。
- 学生 ZIP 解压后以本地文件运行；仅试题、正文、完整内容打印筛选。
- 实际导出抛物线完整打印 PDF，并渲染查看含模块的页面；模块使用静态代表图。
- 独立 agent 抽取原始三个核心模型进行参数网格复核，检查距离和、距离差、焦准比、渐近线距离积、抛物线反射等不变量，最大浮点残差约 `2.85e-14`；另独立审查学生隔离、配置兼容及高度同步代码。

这些验证针对本轮可视化接入，不等于五册教材全部题答或所有原实验室推导已完成数学审定。

```sh
python3 scripts/build_conic_labs.py

python3 scripts/test_conic_labs.py
```

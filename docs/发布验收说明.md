# 发布验收记录

## 本地发布副本

- 发布副本独立于原项目，仓库启动入口是根目录 `index.html`；提供标准库服务器 `serve.py`、macOS 启动脚本和 Windows 批处理。
- 使用全新 Python 3.14 虚拟环境重建全部 101 节，构建结果均为 `rendered`，未出现阻塞问题；随后将完整发布副本放入含空格的中文隔离路径，在该目录之外调用脚本重建一个真实章节。
- 对选择性必修第一册 `x1-2-3` 在隔离目录执行重建与真实 Chrome 验收：89 项检查通过，含 504/200 个教师/学生公式、24 题与答案、学生 ZIP 独立离线打开、教师答案显隐、手机打印面板及试题/答案 PDF。1 条提示为一道长题跨两页，符合打印规则。
- 纯静态扫描通过：11,418 个 HTML/CSS 本地引用、101 个学生 ZIP 及其中 25,692 个引用、43 个可视化资源包、101 节源文件哈希、404 个预构建产物哈希均无错误；337 个文字标记范围未越界或截断公式，49 个可视化锚点与教师/学生页一致。
- 43 个可视化资源包通过其资源校验器；对包含五册入口、全部 `outputs/`、及 `batch/reviews/` 的实际 Pages 目录做闭包扫描，10,666 个本地引用均可达。
- 隔离目录中的全量可视化真实浏览器测试通过：43 个模块、43 个插入章节、1,748 项检查；五册编排配置、导入导出、显隐与撤销等状态测试通过 40 项检查。
- 独立复核原稿至成品的全部 337 条强调标记，师生两版共 674 个 HTML 标注的文字、数学式和图片均保真；49 处插入配置对应的 98 个师生视图锚点全部一致。
- 用临时随机端口启动 `serve.py`，总目录、五册目录、教师页、学生页、学生 ZIP 和章节复核记录均返回 HTTP 200。CI 已加入 Linux/Windows、Python 3.10/3.12 静态与构建回归矩阵。

## 范围与未完成项

- 上述是结构、部署闭包、浏览器、打印与离线包检查，不是 101 节内容的全面数学复审，也不等于已在实际 Windows 桌面、GitHub Actions 或 GitHub Pages 线上环境完成验收。
- 发布仓库为 [cheng-bai/hujiao-math-textbook](https://github.com/cheng-bai/hujiao-math-textbook)，已配置 `origin` 并推送。远程 Linux/Windows 检查以 [CI 工作流](https://github.com/cheng-bai/hujiao-math-textbook/actions/workflows/ci.yml) 为准，线上发布以 [Pages 工作流](https://github.com/cheng-bai/hujiao-math-textbook/actions/workflows/pages.yml) 为准；这些不与本地证据混记。
- 每节的历史 `validation.json` 与旧测试记录是其生成时的证据，不代表发布后全书重新进行数学审定。

- 检查章节身份、默认插入位置、按节加载、跨册隔离、学生包、原文折叠与打印恢复、源稿漂移防护。

## 已发现并修复的两个集成 P1

### P1：旧样章首阅读模块不能代替教材节标识

旧实现从第一个 `.content-module` 的 `data-module` 读取 `sectionId`。必修二 8.1、8.2 沿用多模块样章，首模块分别是 `concept`、`projection`，并非 `bx2-8-1`、`bx2-8-2`。随后查询教材清单得到空结果并提前退出，导致两节可视化编排初始化失败。

修复：页面根元素写入真实的 `data-section-id`；编排脚本优先读取该标识，并以整个 `.book-body` 为锚点及事件容器，不再限于第一个内容模块。

复核：遍历五册 101 个节点，确认只有上述两节具有多内容模块；以 `approved_components()` 和 `page()` 在内存分别生成两节教师、学生页面，四页均包含正确章节身份，相关已选可视化落点的锚点均存在。

### P1：合成阅读模块导致原块索引整体偏移

两节旧样章的第一个原始块均为 `intro`。旧渲染器先在数组开头插入合成 `section`，再按新数组索引给无 ID 块赋值，导致默认锚点相对清单与可视化落点的原始索引整体偏移一位。

修复：在插入合成阅读模块之前，先按原始枚举赋予稳定默认 ID；合成模块仍使用独立的 `<sectionId>-reading`，原来显式命名的模块 ID 保持不变。

复核：重新检查源码执行顺序，并重复上述四页内存渲染；选中资产的所有目标锚点均存在，源索引与输出 ID 一致。

## 公共行为检查

### 按节资源与跨册隔离

- 每册生成独立的 `textbook-catalog-<book>.js`，资产的 `sections`、`placements` 均过滤为本册；实际检查五册清单，未发现跨册落点。
- 页面只注入当前节使用的新增实验 payload；不会把五册全部 HTML 模型装入每个页面。按册清单的轻量元数据保留，用于校验整册编排文件。
- 旧选必一存储键保持不变，其他册使用册别后缀；JSON schema、`sourceBook`、允许章节、固定资源版本及参数均有校验，跨册配置不应被误收。
- 原有圆锥曲线与线面垂直模块未被覆盖；新增模块使用独立资产 ID。旧配置中已有位置与“移除过的默认模块”通过 `bundledDefaults` 保留。

### 原文折叠与移除恢复

- 只在作者指定的对应 prose 落点、源块摘要一致且未声明 `retainProse` 时折叠；用户拖入其他位置的实验不折叠无关文字。
- 原文 DOM 移入可展开容器，不删除源稿；常显摘要、关键条件卡和现有概念强调另行展示。
- 重绘前先恢复原文，之后重新根据当前配置折叠。因此移除、撤销或导入配置不应导致原文丢失或多层套叠。

### 打印恢复

- `book.js` 在生成打印副本时，将 `.visual-condensed` 替换为保存的完整原文，去掉摘要副本和重复卡片，不把网页折叠状态当作打印缺文的理由。
- 正文及完整内容模式打印完整原文；仅试题、试题与答案模式不夹带可视化交互控件。
- 交互模块仅在完整内容模式打印静态代表图，并注明非当前交互参数快照；不能把图中有限采样作为数学证明。
- 原有题目模块与打印选择逻辑保留。本代理未执行打印引擎，不能据此保证所有长题或长答案绝不跨页，分页仍由主代理做实际样页检查。

### 学生资源隔离：额外 P1 已在构建代码修复

- 生成学生正文的路径排除答案、教师解析和教师专用内容；圆锥曲线当前节使用独立的 `conic-<kind>-student.js`，未发现学生包混入 `conic-*-teacher.js`。
- 只读检查 6 个已生成 ZIP，页面所引用脚本均在包内，没有仅依赖本机 HTTP 端口的脚本引用。
- **另发现 P1：旧 `module-data.js` 内的 `ellipseHtml` 含 `<details class="teacher">`，标题为“教师备课：原题、推导与边界”，含原题及推导。学生页和学生 ZIP 直接携带该文件，CSS 隐藏不等于内容隔离。**
- 主代理已修复：构建器用 BeautifulSoup 实际删除 `.teacher`、`.teacher-only`、`.answer` 节点，生成独立 `module-data-student.js`；学生页及 ZIP 的资源允许清单只选该文件，教师保留原文件。模型状态与规范来源标识保持兼容，不以改编排身份解决角色内容隔离。
- 独立复验实际原始 payload 的同一清理流程：找到并删除 1 个教师块，移除后相关选择器和教师备课标题均不存在，脚本与两个滑块仍在。另一个旧线面垂直 payload 不含这些教师选择器。Python 编译检查再次通过。
- 生成后的文件及最终全部学生 ZIP 仍须在统一重建后核对；目前确认修复代码与实际输入的清理结果，不冒充最终发布包已经刷新。

## 源块摘要防漂移与圆锥曲线常显公式

- 构建器对原始 JSON block 使用 `ensure_ascii=False`、紧凑分隔符序列化后取 SHA-256，记录于指定落点的 `sourceSha256`。
- 页面生成器对原始 `data.blocks` 采用相同规则计算摘要，输出为原文块的 `data-visual-source-sha`。它不对图片改写后的渲染副本取摘要，因此不会因离线图片路径替换而误判。
- 运行时要求落点章节、ID 和摘要同时一致，且不含 `retainProse`，才允许折叠。源稿改变而实验清单尚未重新审校时，应继续显示完整原文，动态图可保留，不会静默隐藏新文字。
- 独立检查三个分组共 41 个落点：原文块按规范计算的摘要均能由页面生成器输出；仅在内存修改各目标正文后，全部 41 个旧摘要均失配。另直接提取并执行运行时的实际 `audited` 判定表达式，验证新鲜摘要允许折叠、漂移摘要拒绝折叠、`retainProse` 拒绝折叠。
- 椭圆、双曲线的常显原生 MathML 同时列出两种坐标轴方向的标准方程，正负号正确；抛物线列出横向、纵向以及正负开口，且保留 `p>0`。
- 主代理已按复核建议显式补充椭圆 `a>b>0`、双曲线 `a>0,b>0` 条件，避免标准方程与可选退化演示混同。原定义与完整推导仍应展开可读、打印恢复。

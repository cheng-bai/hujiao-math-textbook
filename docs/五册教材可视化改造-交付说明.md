## 编排与教学边界

动态图侧重变化关系、空间结构、边界和反例，让读者通过操作理解冗长说明。重要条件与公式常显；经核对的长说明在屏幕折叠但可展开，源块内容变化时不再自动折叠。7 个含题设、数据或未覆盖解释链的混合段落继续常显。

删除或隐藏模块会恢复对应原文。编排配置按册隔离，支持导出、导入和撤销，保留旧选修一配置兼容。每节只加载当前所需的实验载荷。未接入题篮，未修改另一个工作台项目。

学生版及学生离线包物理剥离教师答案、解析与教师专用内容，不依赖 CSS 隐藏。概念实验本身用于帮助理解，不宣称是无提示的测验材料。

正文及完整打印恢复完整原文；完整打印另带静态代表图，非当前交互状态截图。仅试题、试题与答案模式不混入交互图卡。静态图、有限采样和数值近似均不替代数学证明。

## 可复用资源与限制

36 个新模块已按 Anatomy manifest 1.1 封存为独立资源，位于 `../outputs/教材可视化资源库/{slug}/1.0.0/`，索引为同目录的 `library.sqlite`。带源码、哈希与检查依据，支持固定场景和参数恢复。已封存版本不可直接覆盖，后续内容修改应升级版本。

资源库 mathematics、interaction、offline 检查通过；visual 保持 pending。已有真实浏览器截图与代表性视觉抽查，但不冒充全部模块、全部参数状态逐一人工签核。

本轮完成的是全册筛选、模块实现与插入，不等于全书题答、来源和数学审定。原有批次的题答缺漏、来源冲突和分页疑点仍依各自记录处理，不把旧批次状态当作本轮可视化失败，也不声称已全部消除。

打印保留整题避跨页规则，但超出单页高度的长题不能承诺绝不跨页。本轮抽查代表 PDF，未逐页审计101节点的所有打印组合。完整打印中，静态图卡与整题避跨页的组合仍可能产生零散留白；例如选修二5.1完整打印有图卡后续长题移至下一页的情况，后续可专项优化，不以本轮通过记录宣称打印密度完美。

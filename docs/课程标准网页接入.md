## 重建与检查

- 重建需要 Python 3.10 或更新版本、`requirements.txt` 中的 Python 包 `beautifulsoup4` 和命令行工具 Pandoc；生成后的网页使用仓库内的阅读资源，无需联网。
- `python3 scripts/curriculum_page.py`：从保留原稿与 `corrections.json` 生成局部校订底稿、课标页和阅读脚本，不重建教材章节。原稿指纹不匹配时停止，避免将旧校订套用到新材料。
- 导入修订原稿时，使用 `python3 scripts/curriculum_page.py --source <Markdown路径>`，源文件目录应包含所引用的 `images/`；须同步重新核验校订清单及源稿指纹，不可直接沿用旧清单。
- 样式与行为主档：`scripts/curriculum_reader.css`、`scripts/curriculum_reader.js`。
- 首页入口主档：`scripts/portal_index.py`。`add_curriculum_link` 可幂等补入入口，原有首页内容不变。
- 运行 `python3 -m unittest discover -s scripts -p 'test_curriculum_page.py'` 和 `python3 -m unittest discover -s scripts -p 'test_portal_index.py'`，检查正文、图表、公式块、文件、锚点及首页接入。
- 浏览器另查桌面与手机宽度、首页跳转、目录、搜索、图表、公式及横向溢出。打印样式仅为基础支持，本次不交付 PDF，也不声称全篇打印分页已验收。

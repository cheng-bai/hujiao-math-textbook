# 五册教材图片重绘与难度校准试运行

本目录是独立审阅包，不替换正式教材图片。网页运行依赖的原图副本、KaTeX 与阅读入口均在 `assets/` 中，可将整个目录复制后打开 `index.html`；阅读入口只是前端门槛，不是账号认证。重建仍需要完整项目源码。

## 入口

- `index.html`：10 张原图与程序生成 SVG 并排对照。
- `images.html`：708 张正式引用图片的检索、定位与初分清单。
- `difficulty.html`：30 道原题、主评星级、独立复核和复议证据。
- `708张图片定位与分类.csv/.json`：来源、行号、原图名、尺寸、哈希、使用位置及暂定重绘名。`original_path` 是仓库溯源路径，`package_path` 是包内运行路径。印刷页码未核实处为空。
- `30题难度校准与独立复核.csv/.json`：评分、子问星级、数学证据、分歧和状态。
- `30题原始校准样本.json`：从正式目录抽取的原始题块快照，含来源答案与解析。
- `redraw_samples.py`：10 张 SVG 的纯 Python 标准库生成代码。
- `build_review.py`：从正式章节 JSON 重建索引和本地审阅页。沿用仓库的 Pillow、MarkdownIt 和 KaTeX 环境。
- `evidence/`：浏览器渲染截图与实际检查记录。

## 重建

在项目根目录运行：

```sh
python3 outputs/教材高清图与难度校准-20261021/build_review.py
python3 outputs/教材高清图与难度校准-20261021/verify_review.py
```

评分不是自动从题干推算。`build_review.py` 整理的星级和数学证据是显式校准输入；不应把脚本构建成功理解成数学内容已经全面验收。

## 图片分类口径

708 个来源图片引用均与原图建立 1:1 路径映射，并记录教材/教参角色、章节、引用块、Markdown 行、尺寸、字节数及 SHA-256。仅 10 张样图逐张对照了原图与邻近正文；其余图片的内容类型属于尺寸/版位初分，尚待人工视觉确认。尤其大幅图可能是章首照片，狭长图可能是图组或公式条。建议名称以册/节/核实图号为主；页码未知时不猜。

10 张小样覆盖五册数学结构图。静态 SVG 以保真和可打印为目标，不等于值得交互；拉绳椭圆省略实物画面，长方体和棱柱为有坐标定义的空间投影。所有原始 JPG 仍保留，未重命名、未覆盖。

## 难度校准边界

五星是相对所属课程的教学结构标尺，不是 HCT 换算、错误率或学生实测水平。样本每册 6 道，按正式题块序列等间距取样，适合检验分歧，不代表各册真实星级分布。主评与独立 agent 均读取原答案，属于回顾性评分。当前 26 道有效题中，初评同星 22 道（84.6%）；另 4 道存在构型、有限总体模型、百分位数答案或题干范围问题，暂不定星、不冻结量表。第 27 题的偶数计数在独立复核更正后为 32；原题范围冲突仍在。

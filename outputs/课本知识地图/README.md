# 课本知识地图

独立导航页，覆盖五册主教材的 21 章、80 节；两册建模活动不在本页范围内。每个条目内按知识组保留概念、性质和方法，避免拆词造成语义缺失。跨册主线是教学关联，不声称是严格先修顺序或真题对应关系。

## 来源和边界

`../教材真题框架工作区/framework.md` 是来源底稿，由已有知识大纲归纳，并通过五册整合页核对章节导航；不是教材逐条原文或全面审定的课标。页面链接到对应节教师版而非精确段落；具体内容、范围与位置需回教材核对。这里不是教材全部细目的完整盘点。

## 更新

在发布版项目根目录运行 `python3 outputs/课本知识地图/build_data.py` 从底稿重建 `data.js`。生成器检查 80 节及目标路径；更新后应复查归纳、关联主线和页面。页面直接加载本地脚本，不依赖联网，也不改写教材或试卷页面。

## 画布版

`index.html` 为画布入口：全景呈现各章及少量人工整理的跨章教学关联，进入章后展开教学节和知识组；实线表示组织层级，虚线表示教学关联，并非先修关系。画布使用原生 SVG，支持拖动、缩放及搜索。`previous-list/` 保留旧列表视图；`canvas.js` 中维护少量关联及说明，增加连线前应核对数学含义和来源。节点目前仍来自底稿的知识组，并非完成逐概念标注。

## 函数知识主线样板

画布左侧“函数知识主线”进入概念关系视图。`function-data.js` 独立维护概念、教材节 ID 和关联；选中节点后只显示与它相连的边，点击边或详情列表查看关系及适用条件。搜索可定位概念。`canvas.js` 的 `functionAnchors` 存放已核实的部分节内锚点，其他链接指向相关章节首页。数据是人工教学归纳，不是教材逐字摘录，也不代表函数全部知识点已完成。

## 几何与向量主线

左侧“几何与向量主线”进入 16 个概念、21 条教学关联的专题画布。沿“对象表达—张成与基底—数量积与正交—位置关系—角度与距离”组织推理，不声称覆盖全部几何课程。

`geometry-data.js` 独立维护 `nodes` 和 `edges`。节点含 `desc`（概念）、`pitfall`（条件与边界）、可选 `example`（反例或推导）、`sources`（教材节 ID 与段落锚点数组）；连线含 `from`、`to`、`label`、`explain`。教材锚点均需在对应教师页核验。新增概念时必须解释连线依据，不以章名或相似词代替联系。

重点区分一般基底与正交单位基、方向条件与位置条件、有符号投影与距离、较小平面夹角与指定二面角。示例是教学补充，并非教材原文。复查时运行 JS 语法检查、节点和边完整性检查、来源锚点存在性检查，并在浏览器检查专题切换、搜索、连线详情和窄屏操作。

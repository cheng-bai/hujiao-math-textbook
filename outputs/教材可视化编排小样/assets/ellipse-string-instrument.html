一根绳，怎样约束出椭圆？

先移动笔尖，观察什么变、什么不变；再把两焦点拉开，找出“画得出来”的边界。

课堂上，按这三步试

  1. 先固定焦点。拖动参数角，描述两个距离各自怎样变、总和怎样变。注意：参数角是控制位置的参数，不是 OP 与横轴所成的角。
  2. 再改变焦距。保留总绳长 10，依次试 c = 0、3、4.5。在普通椭圆中，这个参数比就是离心率。让学生预测变扁时哪个量增大，再看读数核验。
  3. 最后试临界值。点“恰好等长”和“焦点过远”，用三角形两边之和解释还能不能画出轨迹。动画只帮助观察，论证要回到距离关系。

具体教学判断：若学生说“距离和固定就一定是椭圆”，先让他比较绳长和焦距。若他根据画面判断圆被压扁，切回两焦点重合，并指出这是斜视投影；不要拿屏幕线长作几何证明。本页未观察任何学生作答，上述仅为备课预判。

# 沪教数学 · 可视化编排小样

更新日期：2026-10-19

## 打开与体验

直接打开本目录的 `index.html`，不需要安装依赖、联网或启动服务。

1. 左侧切换“2.2 椭圆”与“3.4 空间向量的应用”两个概念节选。
2. 右侧资源卡点击“预览”，可以操作已有交互；预览不会改变正文中的实例。
3. 把资源卡拖到正文的虚线插入位置；也可先点击虚线选定位置，再点资源卡的“插入”。手机端用“资源库”打开抽屉，以按钮插入。
4. 每个插入实例的参数独立，可重置、移除；“撤销”可撤销最近30次编排操作，不记录每次滑块操作。
5. “导出编排”保存 JSON；“导入编排”恢复插入位置、固定资源版本、参数及学生可见标记。移动小样时应复制整个目录，而不是只复制 JSON。

初始示例已在椭圆定义后插入一个拉绳模块，可直接操作。编排会尽力暂存到当前浏览器本机存储，但这不是持久备份；请用 JSON 导出保存。不同浏览器、不同打开地址的暂存互不通用。

## 本次复用

- 椭圆拉绳绘图仪：固定半长轴5，观察焦距、两段距离和与退化边界。
- 线面垂直判定：对比平面内两条相交直线与两条平行直线，旋转视角并查看反例。

复制来源、版本及 SHA-256 记录于 `assets/source-records.json`；来源项目和正式教材只读，未被小样改写。必要许可副本保留在 `licenses/`。

模块以沙箱 iframe 嵌入；每个实例使用独立状态和消息标识。嵌入页禁用外部网络请求。导入只接受本小样已知的资源、固定版本及参数结构，不执行 JSON 中的代码。

## 选修一真实章节接入

已将同一套编排器接入选修一教师版和学生版网页。可直接打开以下教师页体验，也可从对应学生页检查可见性隔离：

- `../五册教材教参整合/x1/x1-2-2/teacher.html` 与 `student.html`：椭圆
- `../五册教材教参整合/x1/x1-3-4/teacher.html` 与 `student.html`：空间向量在立体几何中的应用

教师页中打开“可视化编排”，按正文锚点插入模块、调整参数、勾选“学生页显示”，并可导出全册 JSON。学生网页不含答案和教师内容；导入教师 JSON 后只载入已勾选的交互模块。学生离线 ZIP 也包含模块运行资源。完整内容打印以静态图示呈现交互模块，正文、仅试题等打印模式不带该模块。

本机暂存以选修一为范围，并在同一册页面间共享；跨设备或交给学生请导出／导入 JSON。若检测到另一页面并发修改且本页模块参数冲突或未能同步，本页会暂停自动保存，避免覆盖另一页的配置；先导出本页配置，再刷新或导入选定版本。

## 当前边界

- `index.html` 仍是两节概念摘编的独立编排原型，不是已完成的教材全书；真实章节网页保留原教材正文，只插入经教师编排的可视化模块。
- 没有接通试题篮，没有修改另一个正在建设的项目。
- 目前只接入选修一第2.2节和第3.4节的两种可视化资源；其余章节尚未配置资源。
- 导出的 JSON 不包含教材全文、图片或模块代码；学生离线运行请使用章节学生 ZIP，并另行导入教师导出的配置。
- 修改的是渲染／编排脚本和生成的阅读页，不改教材与教参的原始来源文件，也不接入题库项目。
